一、产品说明


1.1 产品介绍


超级收银员是一款应用于无人零售终端（无人售货柜）之上的动态视觉识别产品，可通过分析无人零售终端内摄像头拍摄的视频，准确识别出用户拿取的商品，同时还可识别异物放入、商品开启后放回等多种异常行为。
作为新一代识别方案，超级收银员能够覆盖更大范围的商品，除标准商品，还可通过包装识别如蔬菜水果、现煮食品等各种非标商品。
 同时，产品的整个接入流程也极其简单便捷，业务方只需传输9张规定规格的商品照片，经过短暂的训练，即可完成建模，开始使用识别服务。

3.5 签名机制


对于每个访问请求系统都会进行身份验证，所有API请求中都需要包含签名（Signature）信息，OpenAPI服务通过使用AccessKey和SecretKey进行对称加密的方法来验证请求的发送者身份。AccessKey和SecretKey由服务官方颁发给访问者，其中，AccessKey用于标识访问者的身份；SecretKey是用于加密签名字符串和服务器端验证签名字符串的密钥，必须严格保密，只有超级收银员官方和用户知道。


用户在访问时，按照下面的方法对请求进行签名处理：


  1. 使用指定参数构造签名头信息（SignedHeaders）
    SignedHeaders = Lowercase(Host) + ”;“ + Lowercase(Content-Type) + “;” + Lowercase(X-Request-Date)
    X-Request-Date: UTC timestamp，单位: 毫秒
    RequestPayload: HTTP body内容，如果body为空，则按照空字符串进行hash计算
  2. 使用请求参数构造规范化的请求字符串（Query String）
  • 按照参数名称的字典顺序对请求中所有的请求参数进行排序，如果有同名key，则按照value进行排序
  • 对每个请求参数的名称和值进行编码，名称和值要使用UTF-8字符集进行编码。
  • 对编码后的参数名称和值使用英文等号（=）进行连接，如果没有参数值，则以空字符串代替，但不能省略“=”
  • 再把英文等号连接得到的字符串按参数名称的字典顺序依次使用&符号连接，即得到规范化请求字符串

  1. 使用指定参数构造请求信息（HashedRequest）
    HashedRequest = Lowecase(HexEncode(Hash.SHA1(Request))
    Request = HTTPRequestMethod + “\n” + CanonicalURI + “\n” + QueryString + “\n” + SignedHeaders + “\n” + HexEncode(Hash.MD5(RequestPayload))
    RequestPayload: HTTP body内容，如果body为空，则按照空字符串进行hash计算
  2. 使用参数构造最终签名信息（Signature）
    Signature = HexEncode(HMAC(SecretKey, StringToSign))
    StringToSign = Algorithm + '\n' + HashedRequest
  3. 将签名结果信息设置到请求头Authorization，具体头信息参照3.4

# -*- coding:utf-8 -*-
import hashlib
import hmac
from urllib.parse import urlencode, quote


class AkskCli:
    """
        请求头中必须参数
            Content-Type:
            Authorization: HMAC-SHA1 <access_key>:<signature>
            Referrer:
            X-Request-Date: <12345678>
        注意事项:
            set_params 中参数按照字符代码以升序顺序对参数名进行排序依次给出，如果没有参数值，则以空字符串代替。
    """
    def __init__(self, ak, sk):
        self.__access_key = ak
        self.__secret_key = sk
        self.__host = ""
        self.__uri = ""
        self.__params = dict()
        self.__body = ""
        self.__content_type = "application/json"
        self.__method = ""
        self.__alg = "HMAC-SHA1"

    self.__alg = alg_str

def get_algorithm(self):
    return self.__alg

def get_access_key(self):
    return self.__access_key

    return self.__secret_key

    self.__host = host_str

def get_host(self):
    return self.__host

def set_uri(self, uri_str):
    self.__uri = uri_str

def get_uri(self):
    return self.__uri

def set_params(self, params_map):
    self.__params = params_map

def get_params(self):
    return self.__params

def set_body(self, body_str):
    self.__body = body_str

def get_body(self):
    return self.__body

def set_content_type(self, ct_str):
    self.__content_type = ct_str

def get_content_type(self):
    return self.__content_type

def set_method(self, method_str):
    self.__method = method_str

def get_method(self):
    return self.__method

def get_x_request_date(self):
    return str(int(time.time()))

def get_signed_headers(self):
    return str.lower(self.get_host()) + ";" + str.lower(self.get_content_type()) + ";" + self.get_x_request_date()

def get_md5_body(self):
    return hashlib.md5(self.get_body().encode('utf-8')).hexdigest()

def get_query_string(self):
    return urlencode(self.get_params())

def get_request_str(self):
    return self.get_method() + "\n" + self.get_uri() + "\n" +self.get_query_string() + "\n" + self.get_signed_headers() + "\n" + self.get_md5_body()

def get_string_to_sign(self):
    hsa1 = hashlib.sha1()
    hsa1.update(self.get_request_str().encode('utf-8'))
    return self.get_algorithm() + "\n" + hsa1.hexdigest()

def get_signature(self):
    return hmac.new(
        self.get_secret_key().encode('utf-8'),
        self.get_string_to_sign().encode('utf-8'),
        hashlib.sha1).hexdigest()

4.1.5 常规SKU修改

​

五、识别规则

  • 无法识别：识别失败，无法识别用户拿取的商品或数量
  • 未知商品：识别失败，SKU列表里未包含用户拿取的商品
  • 异物拿放：识别失败，用户放入非柜内原贩卖的商品或拿取明显异物（前人放入的袋子等等），包含补货行为
  • 疑似设备故障：识别失败，视频异常（0秒、黑屏、无视频载入、测试视频等）、关门后视频未结束（长达1分钟以上）、关门前视频提前结束、开门后视频才开始、非货柜视频
  • 故意遮挡：识别失败，用户故意遮挡摄像头或商品导致无法识别拿取的商品或数量
  • 其他告警：常见案例包含：
  • 用户拿商品出视频可见范围后，过了30秒又放回柜内（在30秒内放回柜内则正常识别）
  • 用户将柜内商品放置门缝边，疑似窃取行为
  • 用户拆封、毁坏商品
  • 客户贩售或用户拿取无人售货柜违禁物品
  • 运营人员开门清洁或维修设备

六、硬件要求

视频文件规格及要求 ：

尺寸：1280x720像素

帧率：最小15帧/秒，最大24帧/秒 （过高和过低的帧率均会影响识别精度，且高帧率浪费带宽）

码率：最小2m/秒，最大6m/秒

​

视频成像：

1. 尽量减少曝光时间以消除运动模糊。

2. 自动曝光调节速度要尽量快，避免开门后由于过曝导致看不清取货动作。

3. 视频需包含开门前2秒及关门后2秒，如视频中没有开门前画面或关门后视频长达1分钟以上会告警疑似设备异常。

4. 镜头焦距需根据视角和柜体进行测算，以刚好覆盖取货区域为准，焦距过长会有死角，过短则浪费视野。
